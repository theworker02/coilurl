# coilurl

Coil filesystem url paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/coilurl/

## Install / run

```bash
git clone https://github.com/theworker02/coilurl.git
cd coilurl
node src/cli.js
node --test
```
